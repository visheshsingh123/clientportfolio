# Yuvraj Singh Somvanshi

A responsive, static personal website for a Surat-based real estate agent and author.

## Run locally

From this directory:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

No build or dependency installation is required. Deploy `index.html` and `style.css` on any static host.

## Personalize

- Replace the two `.photo-slot` elements with his photographs.
- Replace the three decorative `.trophy-slot` elements with trophy photographs.
- Replace the illustrative hero image and landscape with approved images.
- Book covers use the supplied `cover1.jpeg` and `cover2.jpeg` images.

WhatsApp and phone links use +91 95580 26250. Images load from Unsplash; optional web fonts load from Google Fonts, with local fallback fonts.
